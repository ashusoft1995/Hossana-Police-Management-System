# Hossana Police Management System

A full-stack web application for Hossana City Police Department to support
crime reporting, criminal records, investigations, traffic accident reports,
human resource management, and police administration.

## Technology Stack

- UI/UX Design: Figma
- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: Java, Spring Boot, Spring Security
- Database: MySQL
- ORM: Spring Data JPA / Hibernate
- Authentication: JWT and role-based access control
- Version Control: Git and GitHub
- API Testing: Postman

## Main Actors

- Citizen
- Police Head
- Detective and Investigation Police
- Criminal Preventive Police
- Traffic Police
- Traffic Officer
- HR Manager
